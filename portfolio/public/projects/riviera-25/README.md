# riviera-25 assets

Drop 3 to 5 project images here for the carousel.

- Format: WebP preferred (JPG fallback accepted)
- Max size: 1200x800 px, each under ~200KB
- Filenames: 1.webp, 2.webp, 3.webp, ... (ordered)

Until images are added, the carousel shows a "Preview coming soon"
placeholder. After adding, list the filenames in the project's `images`
array in lib/planets.ts.
